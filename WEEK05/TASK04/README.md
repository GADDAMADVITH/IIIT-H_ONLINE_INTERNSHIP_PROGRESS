# WEEK 04 - YOLO Dataset Preparation and Annotation

## Objective
The objective of this task was to prepare a custom dataset for YOLO object detection training.



# Work Completed

## 1. Video Collection
A real-world vehicle movement video was selected for object detection.



## 2. Frame Extraction
Frames were extracted from the video using FFmpeg.



## 3. Dataset Splitting
Extracted frames were divided into:

- Training Set
- Validation Set
- Test Set


## 4. Annotation
Label Studio was used to annotate objects using bounding boxes.

## 5. Metadata Files
Created:
- data.yaml
- train.txt
- val.txt




## Outcome
Successfully prepared a custom YOLO-compatible dataset with annotations and metadata files for object detection training.
